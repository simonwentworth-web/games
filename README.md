# Games

| Game | What it is |
| --- | --- |
| [Unique Animal Generator](unique-animal-generator/) | Cross two cat breeds or two dog breeds and meet a one-of-a-kind designer pet: an AI portrait, a breed name, three name ideas and one-tap sharing. |
| [Creature Lab](creature-lab/) | Splice any two of 62 animals into a brand-new species (some pairs unlock legendary creatures) with an AI portrait, field notes, superpowers, name ideas and sharing. |
| [Brain Bridge](brain-bridge/) | An adaptive 11+ trainer for the Bristol Grammar School and QEH entrance exams and interviews: one 40-minute session a week, every full session earns a games token. |
| [Study Quest](study-quest/) | MYP2 home learning across six subjects (maths, science, English, Spanish, I&S, computing): finish a 15–20 minute session, earn a token, trade it for 40 minutes of gaming — with a full parent-visible record of every session. |

Open `index.html` at the repo root for a page that links to all of them. Each game lives in its own
folder with its own README, and runs as a plain static site.
